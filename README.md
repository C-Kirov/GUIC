# GUIC 2.0 — 图形化时钟

一款纯 Win32 API 实现的桌面图形化时钟（C++14 + MinGW-w64 静态链接，无运行时依赖）。

版本：**2.0.1.0**（2.x.x.x：主版本.次版本.构建号.修正号，见 src/version.h）

## ✨ 功能特性

- 🕐 **时钟**：日期时间实时显示，支持特殊日期/节气标注（special_days.txt 可编辑，自动创建默认节日表）
- 📅 **农历**：在线同步（香港天文台官方《公历与农历日期对照表》，HTTPS，免密钥）+ 本地计算兜底（1900–2100），天干地支纪年与生肖
- ⏱ **倒计时**：一次性倒计时 / 每日倒计时（含备注），到点提示
- 💬 **消息**：自定义显示消息，自动换行
- 🌦 **天气**：wttr.in 实时天气（城市可配置，后台线程获取不卡界面）
- 🌍 **世界时钟**：8 个时区（读取注册表 TZI，自动处理夏令时）
- 🕘 **模拟时钟**：指针式表盘
- 🛰 **NTP 校时**：多服务器 SNTPv4 查询 + Marzullo 共识算法 + EWMA 平滑偏移
- 📡 **局域网 NTP 服务器**：可自定义端口，为局域网设备校时
- 🌐 **Web 控制面板**：浏览器远程开关显示项/改消息/切语言（端口可自定义）
- ✍ **国际化**：简体中文 / English 运行时切换（菜单、对话框、Web 面板）
- 💯 **无边框模式**：边缘缩放 + 任意拖动
- 📝 **work.txt**：外部文本文件实时显示（修改后自动刷新）

## 🖥 系统要求

- Windows 7 及以上（64 位）
- 静态链接，**无需**安装任何运行时（VS 运行库等）

## 📦 使用说明

- 主界面为纯绘制窗口，所有操作在右上角 **菜单**（分组子菜单：设置/显示/服务器/时钟/语言/关于）
- 显示项开关带复选标记，服务器运行状态实时打勾
- **服务器端口设置**：菜单 → 设置 → 服务器设置…（运行中的服务器自动按新端口重启；NTP 默认 123 被 Windows 时间服务占用时可改到其他端口）
- **语言切换**：菜单 → 语言（菜单与标题即时切换）

## ⚙ 配置文件（均位于 exe 同目录）

| 文件 | 说明 |
|---|---|
| config.ini | 窗口/字体/颜色/倒计时/显示项/天气/NTP/服务器端口等设置 |
| special_days.txt | 特殊日期与节气（格式：名称|月|日|时|分|每年|年|节气） |
| work.txt | 外部文本，修改即自动刷新显示 |
| log.txt | 运行日志（NTP/天气/服务器/系统信息） |

## 🔨 构建

### 方法一：CMake（推荐）

~~~powershell
cd GUIC2.0
cmake -G "MinGW Makefiles" -B cmake-build -DCMAKE_BUILD_TYPE=Release
cmake --build cmake-build
# 产物：build/GUIC_2.exe
~~~

### 方法二：Code::Blocks

打开 GUIC 2.0.cbp，选择 **GCC MinGW64 Compiler** 构建即可（输出到 build/GUIC_2.exe）。

> 注：源码为 GBK 编码；CMake 已包含 windres 的 -I src/ 参数以定位 .ico/.manifest。

## 📁 目录结构

~~~
GUIC2.0/
├── src/                    # 源码（Win32 GUI + 逻辑层）
│   ├── main.cpp            # 入口（Winsock 进程级初始化）
│   ├── windowproc.cpp      # 主窗口过程（菜单/定时器/服务器）
│   ├── config/             # 配置（INI/特殊日/网络时间）
│   ├── utils/              # 网络/NTP/天气/农历/HTTP服务器/日志/渲染
│   ├── dialogs/            # 全部对话框
│   ├── i18n.*              # 国际化字符串表（中/英）
│   ├── version.h           # 版本号 2.x.x.x
│   └── resource.*          # 资源（图标/清单/VERSIONINFO/对话框模板）
├── build/                  # 构建产物 + 运行时数据
├── doc/架构.txt            # 架构说明
└── CMakeLists.txt          # CMake 构建脚本
~~~

编码约定：所有源文件为 GBK/GB18030 编码（非 UTF-8），修改时注意编码。

构建方式：
  1) Code::Blocks：打开 GUIC_2.0.cbp，选择 GCC MinGW64 编译器构建，输出 build/GUIC_2.exe
  2) CMake：cmake -G "MinGW Makefiles" -S . -B cmake-build && cmake --build cmake-build
     产物统一输出到 build/GUIC_2.exe（RUNTIME_OUTPUT_DIRECTORY 指向 build/）；
     注：CMakeLists 已包含 windres 的 -I src/ 参数以定位 .ico/.manifest

运行数据（与 exe 同目录）：
  config.ini        显示/字体/颜色/倒计时/服务器 等配置
  special_days.txt  特殊日期（名称|月|日|时|分|每年|年|节气）
  work.txt          外部文本，修改时间变化时自动重绘显示
  log.txt           运行日志

Winsock 生命周期（修复后）：
  WinMain 启动时 WinsockInit()（进程级引用计数），退出时 WinsockShutdown()；
  GetNetworkTime/FetchWeather 仅防御性调用 WinsockInit()，不再各自 WSAStartup/WSACleanup；
  HTTP/NTP 服务器线程因此不再出现 WSANOTINITIALISED(10093) 错误。

========================================
wx 版为独立工程（与 WinAPI 版完全隔离）：C:\Users\czz18\Desktop\AIWorkSpace\GUIC2.0-wx\
基于 wxWidgets 3.3 (MinGW-w64 静态库, C:\wxWidgets) 的完整 GUI 迁移版：
  main.cpp          wxApp 入口（配置/服务器恢复/退出清理）
  frame.h/.cpp      主窗口（菜单/定时器/服务器控制/无边框 WM_NCHITTEST）/绘制

构建：cd wxport && cmake -G "MinGW Makefiles" -B build && cmake --build build
